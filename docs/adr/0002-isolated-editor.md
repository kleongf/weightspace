# The Editor runs isolated, never in this repo

A Claude session working inside this repo can read the Held-out set and the scorer's source, which would quietly break every result. So each Run starts a separate headless Claude Code session (`claude -p`, on the user's subscription, no API key) in a throwaway folder outside the repo, with every built-in tool switched off (`--tools ""`) and exactly two tools served by a local MCP server (`--strict-mcp-config`): a persistent Python sandbox and `evaluate`. As in the original paper, the sandbox holds the Target's weights as arrays the Editor reads and edits in place. When a Patch is saved, the harness diffs the arrays against the Baseline into a sparse list of changed weights. The Held-out set never enters the run folder, and the harness ships with a test that proves it. The cost is extra plumbing, plus the loss of the interactive Code tab as the Editor, which was the original plan.

## How the sandbox is enforced (2026-11-17)

The MCP server (`weightspace.server`) is trusted: it owns the Eval budget, the Turn limit and the run record, and it never builds the Held-out set. The Editor's Python runs in a separate worker process under macOS `sandbox-exec`. That profile hides the repo except the Target's weights, the virtual environment and the five modules the worker needs (`weightspace.tasks`, which can generate the Held-out set, is unreadable), hides the Hugging Face cache and Claude's transcripts, blocks the network, and allows writes only to the run's sandbox folder and the user's temporary folders. `tests/test_session.py` proves each of these, and fails when the profile is loosened. Gradient functions are replaced with ones that refuse, on top of the transcript check the card asks for.

The worker holds the only copy of the model, because two copies swap on a 16 GB Mac. So `evaluate` generates inside the Editor's process, and an Editor that monkeypatched the generation code could mislead its own Practice scores. Held-out scoring happens later, in a fresh process that applies only the saved Patch to a clean Baseline, so such a change never reaches a result.
